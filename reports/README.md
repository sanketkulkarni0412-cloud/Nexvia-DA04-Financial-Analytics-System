# Generated Financial & Risk Reports

This directory stores output artifacts, exported financial workbooks, PDF statement summaries, and model validation documents produced by the system.

## Output Structure
- `monthly_statements/`: Generated P&L, Balance Sheet, and Variance workbooks (`.xlsx`).
- `scorecards/`: Exported credit risk scorecard tables and risk-tier segmentation summaries.
- `pdf_exports/`: Formatted executive one-pagers and monthly packets for stakeholder review.
