# Qlik Sense & Visual Business Intelligence

This directory stores scripts, data models, and specifications for interactive executive dashboards in Qlik Sense and advanced Excel Power Pivot.

## Planned Assets (Phase 6)
- `load_script.qvs`: Qlik Sense data load script establishing associative connections to the SQL warehouse.
- `data_model_spec.md`: Dimensional relationships and key field associations for the Qlik associative engine.
- `dax_measures.txt`: Pre-built DAX formulas for Microsoft Excel Power Pivot alternatives (e.g., Dynamic NIM %, Running Portfolio Total, Period-over-Period Variance %).
- `dashboard_layout_spec.md`: User interface wireframes and KPI layout specifications for executive review.
