# Dataset Directory

This directory stores raw and curated data for the **Financial Analytics and Risk Reporting System (DA-04)**.

## Structure
- `raw/`: Unmodified raw source data (e.g., Lending Club loan data CSV).
- `processed/`: Validated, cleaned, and standardized datasets ready for database ingestion.
- `sample/`: Sample subsets (e.g., 5,000 to 10,000 rows) for rapid unit testing and local development.

## Recommended Dataset
- **Lending Club Loan Data:** Selected for its comprehensive coverage of loan amounts, interest rates, repayment status, borrower demographics (FICO, DTI, income), and default histories.
